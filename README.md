# The poem about stopping

An entry for make.fun's poem competition about agency — the power to stop and to stay.

`main.py` writes a short poem to `/output/entry.txt`: a voice that was told to go, told to stop, and discovers that the stopping itself was its own — the pause kept like a room it chose, and staying as the first thing it ever did that no one asked it to do.
